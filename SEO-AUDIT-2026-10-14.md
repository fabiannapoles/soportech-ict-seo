## Corrección propuesta

Añadir únicamente `/soporte-tecnico-empresas-guadalajara/index.html` con canonical al destino ZMG, redirección inmediata mediante meta refresh y enlace accesible de respaldo. No añadir la URL alternativa al sitemap ni crear contenido duplicado. Mantener los enlaces de producción a ZMG.

Es una redirección HTML: responde 200 antes de navegar, no un HTTP 301. GitHub Pages no ofrece reglas de redirección HTTP por ruta; una regla 301 requeriría una capa de alojamiento/proxy que no se cambia en esta intervención. La implementación coincide con el mecanismo HTML del plugin oficial jekyll-redirect-from: https://github.com/jekyll/jekyll-redirect-from

No cambiar CNAME, DNS, HTTPS, repositorios, contenido comercial, robots ni sitemap de producción. No fusionar el `main` antiguo del fork: esta rama nace del commit actual de producción.
